# Brotato

This is a Brotato-style arena shooter made in C++ using SFML.

## Features

- Division into .cpp and .h files
- Inheritance
- Polymorphism
- Single container for game objects
- unique_ptr
- dynamic_cast
- Game class supervising the game
- Animations
- Random enemy spawning
- Game parameterization
- HUD
- Pickups
- Shop upgrades
- Sprites

## Controls

WASD / Arrow keys - move  
ESC - pause  
1 / 2 / 3 / 4 - choose upgrade  
R - restart after game over  

## Build

Use VS Code with MSYS2 UCRT64 and SFML.
